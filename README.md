# joon-settings

Ubuntu·macOS 환경과 명령줄 도구를 다시 설정할 때 사용하는 설정 파일과 실행 스크립트 모음. 항목별 문서에서 필요한 설정만 적용.

| 항목 | 구성 |
| --- | --- |
| [셸과 oh-my-zsh](docs/02-shell-zsh.md) | 플러그인, 자동 제안, 별칭과 셸 모듈 |
| [Chrome 검색 단축키](docs/07-chrome.md) | 주소창 검색 엔진 JSON과 내보내기 및 복원 도구 |
| [터미널 도구](docs/08-terminal-fun.md) | 스크린세이버, 시계, 날씨, Zellij와 Cava |
| [오디오 도구](docs/09-audio-tools.md) | `listen` 재생기와 로컬 음악 기록 |
| [Ubuntu 한글 입력](docs/10-ubuntu-korean-input.md) | kime 설정과 XIM 패치, Zellij 클립보드 |
| [MX Master 4](docs/11-mx-master-4.md) | Ubuntu의 Solaar 제스처와 GNOME 캡처, macOS의 Logi Options+와 Rectangle 창 배치 |

`files/`는 설치할 설정과 런처, `scripts/`는 항목별 설치 및 복원 도구, `patches/`는 고정 버전의 소스에 적용하는 패치입니다.
